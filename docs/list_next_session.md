# nova::list 현재 상태와 인계

갱신일: 2026-11-04.

## 확정한 구현

- 길이를 O(1)에 아는 기본 list 반복자 및 같은 원소 타입의 연속 반복자는 가까운 끝에 reserve_front/reserve_back으로 직접 예약·생성한 뒤 회전합니다.
- 자기 범위는 예약 전에 시작 인덱스와 개수를 저장합니다. 앞 삽입에서는 추가된 개수만큼 원본 인덱스를 보정하고 입력 순서를 유지합니다.
- 역방향/이동 어댑터 등 나머지 반복자는 기존 임시 버퍼 경로를 유지합니다. 한 블록 이하에서는 vector, 큰 범위에서는 list 버퍼를 사용합니다. 길이를 모르는 입력은 추가 순회 없이 vector에서 청크로 전환합니다.
- 생성 실패 시 추가 원소를 제거합니다. 회전 및 throwing move 경로의 basic guarantee는 기존 계약을 유지합니다.
- 메인 배열에 원소가 남아 있으면 삭제한 영역을 capacity 및 앞뒤 여유에 포함해 재사용합니다. 원소가 모두 외부 블록으로 넘어가면 메인 배열을 반환합니다. 빈 목록의 optimize는 저장소를 모두 반환합니다.
- allocator가 한 블록을 할당할 수 없으면 max_size는 0이며, 양수 확장은 length_error로 거부합니다.
- 공개 API와 내부 구현은 snake_case, C/C++은 UTF-8 BOM 및 기존 CRLF를 유지합니다.

현재 헤더 SHA-256: `094c8456082aee62a7c7b829e663e0dbc5b1efd302a8c50107c0b9002624204e`.

## 검증과 성능

- 일반 Release: run_list_harness.ps1, 리스트 CTest 2/2 통과.
- 메모리 진단: run_list_harness.ps1 -AddressSanitizer, MSVC Release ASan CTest 2/2 통과, ASan 오류 보고 없음. 최종 결과는 [검증 기록](list_validation.md)을 확인합니다.
- 직접 삽입과 임시 vector의 같은 날 A/B: NativeHeap 시간 4회, 요청량 추적 2회 성공. 10만 개의 네 타입/세 위치/두 순서 24개 시간 중앙값이 모두 감소했습니다. 뒤 삽입 최대 요청량은 정수/64B 구조체/짧은 문자열 약 33.3%, 긴 문자열 약 10.0% 감소했습니다.
- 128개 긴 문자열 중간 삽입은 순서별 결과 방향이 달라 작은 차이의 개선을 확정하지 않습니다.
- 상세 조건, 원자료, 재현 명령은 [직접 삽입 검증](list_direct_validation.md)에 보존했습니다. 자기 범위 및 큰 기존 목록의 성능까지 일반화하지 않습니다.

## 결정과 남은 확인

- 확정: sized 범위를 임시 vector 방식으로 일괄 복원하는 이전 계획은 직접 삽입으로 대체했습니다. [청크 실험 기록](list_chunk_validation.md)은 과거 구현의 비교이며 현재 구현의 성능 근거로 사용하지 않습니다.
- 유지: 크기를 모르는 입력의 청크 전환, allocator 한도, 메인 배열 재사용, iterator 무효화 계약과 기존 예외 테스트.
- 보류: 일반 iterator 순회 최적화와 블록 크기 조정은 별도 A/B 작업입니다. 기존 미채택 후보를 근거 없이 다시 적용하지 않습니다.
- 미검증: 최신 헤더의 Linux GCC/Clang 및 Linux ASan+UBSan. 로컬 확인 경로에는 GCC/Clang이 없고 WSL에는 docker-desktop만 있습니다. 기존 CI 구성은 있지만 이번 미커밋 변경으로 실행된 CI 결과는 확인하지 않았습니다.
- 이번 범위의 구현 작업은 마쳤으며, 남은 최종 검증 항목은 다른 컴파일러에서의 실행입니다. 배포/게시/설치/커밋은 수행하지 않았습니다.

## 작업 규칙

기존 미커밋 변경과 원자료를 보존합니다. 전체 checkout/reset을 사용하지 않습니다. 코드·테스트·문서를 먼저 정리하고 기능 하니스를 실행하며 실패 수정 시 필요한 재검증을 합니다. 빌드/실행은 BelowNormal, 논리 CPU 하나, 병렬 작업 하나, MSVC /maxcpucount:1 /p:CL_MPCount=1, /cgthreads1, /CGTHREADS:1입니다. 콘솔 전역 상태는 변경하지 않습니다.
