# NovaContainers v1.0.0

C++20 헤더 전용 컨테이너 라이브러리의 첫 정식 배포 기준입니다. 기존 v1.1.0 및 v2.0.0 사전 게시를 정리하고, 최신 리스트 개선을 포함한 소스를 v1.0.0으로 통합합니다. 소스 커밋 이력은 유지합니다.

## 제공 기능

- `nova::hash_map`, `nova::hash_set`: open addressing 기반 조회, 이종 키 조회 및 allocator 지원.
- `nova::flat_map`, `nova::flat_set`: 정렬된 연속 저장, 이진 탐색 및 대량 데이터 구성.
- `nova::list`: 블록 기반 O(1) 인덱스 접근, 양끝 확장, 중간 삽입·삭제, random-access iterator와 표준 정렬 지원.
- `list::optimize()`로 연속 저장 상태를 구성하고, `blocks()`, `contiguous_view()`, `for_each()`로 순회할 수 있습니다.
- 공개 API와 내부 이름은 `snake_case`를 사용합니다. 집계 헤더는 `<NovaContainers/nova_containers.hpp>`입니다.

## 이번 리스트 개선

- 개수 지정 삽입의 임시 원소 배열을 제거했습니다.
- 기본 list 반복자 및 같은 원소 타입의 연속 반복자 범위는 가까운 끝에 직접 예약·생성합니다. 자기 범위 삽입을 지원합니다.
- 그 밖의 반복자는 작은 vector와 큰 청크 버퍼를 사용하며, 단일 패스 입력도 한 블록을 넘으면 청크로 전환합니다.
- 메인 배열에서 삭제한 영역은 여유 용량으로 재사용합니다. 살아 있는 원소가 전부 외부 블록으로 넘어가면 메인 배열을 반환합니다.
- allocator가 한 블록도 할당할 수 없으면 `max_size()`가 0을 반환하고 양수 확장을 거부합니다.
- 자기 범위, allocator 한도, 예외 처리 및 저장소 재사용 테스트와 재현 가능한 A/B 원자료를 추가했습니다.

## 예약 API

리스트는 `reserve_front(n)`, `reserve_back(n)`만 제공합니다. `n`은 해당 방향에 추가할 원소 수입니다. 일반 `list::reserve()`는 제공하지 않습니다. 이전 사전 게시 소스를 사용했다면 다음과 같이 변경합니다.

```cpp
if (target_size > values.size()) {
    values.reserve_back(target_size - values.size());
}
```

구조 변경 후에는 iterator를 다시 얻습니다. 실제 `optimize()` 재구성은 기존 원소 주소와 span도 무효화합니다.

## 성능 자료

같은 날 MSVC x64 Release에서 기존 원소 128개에 외부 범위 10만 개를 뒤에 삽입한 A/B에서, 직접 삽입은 임시 vector 방식 대비 최대 동시 할당 요청량이 정수·64B 구조체·짧은 문자열에서 약 33.3%, 긴 문자열에서 약 10.0% 감소했습니다. 요청량은 프로세스 working set과 다릅니다. 다른 크기·플랫폼·자기 범위의 결과로 일반화하지 않습니다.

[조건과 원자료](https://github.com/Nova-DevLab/NovaContainers/blob/v1.0.0/docs/list_direct_validation.md)

## 요구 사항과 검증

- C++20, CMake 3.20 이상, AVX2 지원 x86-64 CPU.
- Windows/MSVC: 전체 Release 테스트 및 벤치마크 타깃 빌드 성공, CTest 5/5 통과.
- MSVC Release AddressSanitizer: 리스트 CTest 2/2 통과.
- 빌드와 테스트는 BelowNormal, 단일 논리 CPU, 병렬 작업 하나로 수행했습니다.
- 이번 게시 과정에서 성능 벤치마크를 재측정하지 않았습니다. 위 수치는 저장소에 보존된 같은 날 A/B 기록입니다.
- 최신 소스의 Linux GCC/Clang 및 Linux ASan+UBSan 실행은 미검증입니다.

헤더 전용 라이브러리이므로 GitHub의 Source code ZIP 또는 tar.gz를 받아 `include/`를 사용하면 됩니다.
